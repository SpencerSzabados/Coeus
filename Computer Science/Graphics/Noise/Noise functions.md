 In nature objects have various levels of detail to their features. Thus, in order for CGI to appear realistic they must also incorporate varying levels of detail to their surface and textures; e.g., surface imperfections such as dirt and dust, wear patterns on paint, etc. Noise functions, or rather one use of noise functions, attempt to recreate these variations in detail by adding random noise to the image.  Random number generators outputs are too harsh (no transitions between neighbouring values) to appear natural when used in computer graphics. Consequently, a number of purpose build functions have been designed for this task.

A noise function, in essence, is a seeded random number generator that accepts multiple parameters; often noise functions interpolate between values to form smooth transitions between neighbouring points. More specifically, the type of noise we are interested in is sometimes called _coherent noise_.

**Definition: (Coherent noise)** Coherent noise is noise generated by a noise function (source) that satisfies:  ^f341a0
   1. Passing the same input value always returns the same output value for a fixed seed.
   2. The output values vary proportionally to changes in input (small changes in input result in small changes in output and large changes in input result in larger changes in output).

When adding together noise functions a summary value known as _persistence_ is used to simplify the representation of each signals amplitude and frequency. 

**Definition: (Persistence)** A signal $S$ (noise function) with frequency $f=b^i$ and amplitude $A$ has _persistence_ $a$ if $A=a^i$. 

Each successive noise function added is known as an _octave_, with each octave being separated by a power of some base frequency and persistence values.
