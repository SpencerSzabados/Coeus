In classical machine learning, or specifically in so called hand designed models, constructing a set of features that properly represents data in a way that features can be easily discriminated ([[Knowledge representation and features]]) is often difficult and has repercussions for the performance of the final model. Deep learning attempts, from one viewpoint, to both better combine this process into the overall design of the machine learning model leading to better feature definitions. The empirical results of deep learning methods motivate this change in paradigm.

More specifically, deep learning methods belong to _representation learning_ methods, as they are try to allow a machine to automatically discover the representations needed for detection and classification of select data features, something older machine learning techniques must carefully engineer for each problem. These models are composed of multiple processing layers feeding data into one another, with each providing some level of abstraction from the previous by extracting features from the data and relaying this new data to the next layer. [[@LeCun_2015]] [[@Goodfellow_2017]]. This is the key aspect of deep learning, that each of these layers help extract feature data are not explicitly designed by humans in all their detail, but instead are _trained_ to fit the desired problem (function in reality).

# Limitations
Currently [2022] the theoretical understanding of deep networks is very sparse. One main conceptual difficulty is the high nonconvexity of such models, which implies first order optimization algorithms (e.g., [[Gradient decent]]) may not lead to optimal values instead converging to bad local stationary points. [[@Fang_2021]]. However, in practice a number of back of the hand tricks (e.g., [[Empirical risk in deep learning#(Batch) Normalization|batch normalization]], random parameter initialization) have developed that enable _reliable_ training of deep network architectures.
