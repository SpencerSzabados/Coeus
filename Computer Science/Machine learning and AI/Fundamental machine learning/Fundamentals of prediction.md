Prediction is, at its core, the problem of fitting a model (probability distribution) to training data. The output generated by a fitted model in response to new data (data that is typically not used during the training process) is referred to as a prediction. Prediction differs from [[Classification and clustering]] in that the later attempts to separate data into distinct classes from which they originate, where the first attempts to model the underlying distribution that generates the data and assign a label to new data that expresses from future event relating to the data point; prediction is also distinguished from [[statistical inference]] by the fact that the data points used in prediction are assigned labels based on their inherent features, rather than some collection of tunable variables. 

The fundamental ideas and (statistical) methods of making _good_ predictions belong to the domains of Detection Theory and Decision Theory.


# Prediction via probability optimization
The central goal of all statistical decision making, and thus decision making within machine learning, is to derive an appropriate formulation of an optimization problem being asked for which a decision rule is the optimal solution. That is, we are searching for functions, algorithms, that map data to decisions, i.e., predictions.


# Predictors and labels
The ideas and definitions of predictors and classification labels are fundamental to the domain.

**Definition: (Predictor)** A _predictor_ is a function $\hat{Y}(x)$ that maps an input $x$ to a prediction $\hat{y}=\hat{Y}(x)$.

**Definition: (Label)** An output $\hat{y}$ from a predictor $\hat{Y}(x)$ is called a _label_ of a point $x$.

When $Y$ is a discrete random variable, each different realizable value is called a _class_ of the prediction problem, just as in [[Classification and clustering]] in boarder statistics; however, these problems differ in their pathology as mentioned above. 

The creation and encoding of suitable labels for prediction problems is an important step in applying machine learning methods to the problem, see [[Knowledge representation and features]], as it is fundamental in expressing the problem considered.


## Binary prediction
The prediction question considered throughout most of [[@Hardt_2022]] is two class prediction, or binary prediction. 

Binary predictors can be framed in terms of [[Hypothesis testing]] between two hypothesis representing the two data labels (class membership). Under this setting an optimal binary predictor takes the form of a likelihood ratio test (LRT). A [[Hypothesis testing#^2cca9a|likelihood ratio test]] (LRT) is a predictor of the form $$\hat{Y} = \mathbb{1}\{\lambda(x)\geq c\}$$where $\lambda = f_X(x|Y=1)/f_X(x|Y=0)$, for some scalar threshold $c>0$. The optimal threshold value $$c^* = \frac{f_Y(0)(L(1,0)-L(0,0))}{f_Y(1)(L(0,1)-L(1,1))},$$
results in minimizing the risk of misprediction in the likelihood ratio test.  ^d0c89c

A LRT partitions $\mathcal{X}$, the sample space, into disjoint acceptance (prediction 1) and rejection (prediction 0) regions. As we are only interested in placing (classifying) $x$ into one of these two regions, we can use any function $h:\mathcal{X}\to \mathbb{R}$ that gives rise to the same threshold rule (value might be different) as predictor; in particular, if $h(x)\leq t$ whenever $\lambda(x)\leq c^*$ and vise versa for some fixed threshold $t$, $h$ will function as a predictor. In fact, for all monotonically increasing functions, $h$, the predictors $\hat{Y}_h = \mathbb{1}\{h(\lambda(x))\geq h(c^*)\}$ are equivalent to that above. 

In many cases the optimal predictor threshold is a likelihood ratio test of two functions. These predictors have serious limitations in practice, in that, to compute the predictor for a given input we need to know the associated probability density function for the positive and negative instances of the problem (the two class distributions). However, at least within machine learning contexts, constructing or assuming a particular density function is not often possible. Thus, we must develop method of approximating this information; e.g., [[Supervised learning]] theory attempts to algorithmically use finite sample data to build predictors.


# Loss functions and risk
[[Point estimation#^45314f|Loss functions]] generalize, and quantify, the notion of how much error exists between a mismatched prediction result and the correct (target) value. Loss functions allow for increased flexibility in modeling. Prediction problems are often reformulated in terms of an [[Empirical risk]] (sample risk) minimization problem which attempts to find values for a predictors parameters that minimize the cumulative loss over a given training set. ^5732be


## Maximum posterior and maximum likelihood 
Observe that minimizing the error of a predictor is equivalent to minimizing its risk under the loss function costs of $L(0,0)=L(1,1)=0$ and $L(1,0)=L(0,1)=1$. In which case the optimum predictor, which reduces from the optimal LRT predictor, is $$\hat{Y}(x) = \mathbb{1}\{\lambda(x)\geq f_Y(0)/f_Y(1)\}.$$
There are a few ways one might use this to determine minimizing labels.


### Maximum posterior
By Bayes rule the above is equivalent to $$\hat{Y}(x) = \arg\max_{y\in\{0,1\}}P(Y=y|X=x),$$and is referred to as the _maximum posterior rule_ (MAP) for binary prediction. See, [[Maximum posterior]].


### Maximum likelihood 
The likelihood function of the above predictor is $\mathcal{L}(x)=f_X(x|Y=y)$. The [[Maximum likelihood]] rule for this predictor is then $$\hat{Y}(x) = \arg\max_{y\in\{0,1\}}f(x|Y=y).$$The maximum likelihood rule is equivalent to the LRT when $f_Y(Y=0)=f_Y(Y=1)$ and the loss function has the values given above; i.e.,, the maximum likelihood rule is equivalent to the MAP rule with a uniform prior distribution for the labels.


# Types of error and successes
Binary predictors can be right and wrong in four different ways. The expected value of these quantities give four rates that help characterize a predictor: $$\begin{align*} \text{True positive rate }&: TPR = P(\hat{Y}=1|Y=1)\\ \text{False negative rate }&: FNR = 1 - TPR\\ \text{False positive rate }&: FPR = P(\hat{Y}=1|Y=0)\\ \text{True negative rate }&: TNR = 1-FPR.\end{align*}$$In addition to these standard statistical measures there are a few more that are commonly used in machine learning.

**Definition: (Precision)** (or positive predictive value) measures the expected fraction of relevant instances, and is given by $$P(X=1|\hat{Y}=1) = f_X(1)\cdot TPR/(f_X(0)\cdot FPR + f_X(1)\cdot TPR).$$
**Definition: ($F_1$-score)** The harmonic mean of precision and recall, that is, $$F_1 = 2TPR/(1+TPR+(f_X(0)/F_X(1))FPR).$$Combining precision and recall of a classifier into a single score.
  
**Definition: (False discovery rate)** Equal to the expected ratio of the number of false positives to the total number of positives; i.e., $FDR = E[FP/P]$.


## Receiver operating characteristic curve 
Risk minimization of a predictor can be viewed as trying to optimizing for the best achievable balance between $TPR$ and $FPR$, i.e., $$R(\hat{Y}) = E[L(\hat{Y},Y)] = \alpha FPR+\beta TPR+\gamma,$$for constants $\alpha,\beta\geq 0$ and $\gamma$; For all values the risk-minimizing binary predictor remains an LRT, this follows from [[#^802e2b|Neyman-Pearson Lemma]].

**Definition: (Probabilistic predictors)**  Let $X$ be a random variable, a Binary _probabilistic predictor_ $Q$ returns 1 with probability $Q(x)$ and $0$ with probability $1-Q(x)$.

Probabilistic predictors are a method of modeling predictors in a generalized fashion.

**Lemma: (Neyman-Pearson)** Suppose we are given a continuous likelihood function $\mathcal{L}(x|y)$. Then the probabilistic predictor that maximizes $TPR$ subject to the constringent $FPR\leq \alpha$ is a likelihood ratio test. (A modified version of the statement given in [[@Hardt_2022]].) ^802e2b

The _receiver operating characteristic (ROC) curve_ is a property of the joint probability distribution of $X$ and $Y$, that shows the best possible true positive rate that can be achieved given any predictor that has false positive rate of $0\leq\alpha\leq 1$, by tracing out the maximal $TPR$ for any given $FPR$.

Due to the Neyman-Pearson lemma we can derive several useful properties about ROC curves.

**Theorem: (Properties of ROC curves)** ROC curves satisfy:
  1. The points $(0,0)$ and $(1,1)$ appear on the ROC curve.
  2. The ROC curve must lie above the main diagonal.
  3. The ROC curve is concave (down).

A popular summary statistic for evaluating the quality of a decision function is the area under its associated ROC curve, a value abbreviated to $AUC$. However, can only serve as an indicator, two ROC curves can have the same area while having different characteristics (one being far better than the other).
