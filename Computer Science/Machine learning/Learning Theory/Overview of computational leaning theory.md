# Overview 
Computational Learning Theory (CoLT) or simply Learning Theory is a research field devoted to studying the design and analysis of machine learning algorithms, and quantifying the complexity involved in learning problems. Emphasising rigorous mathematical analysis of designed algorithms and methodologies using techniques from various connected fields such as probability, statistics, optimization, information theory and geometry. While the domain is rooted in theory practicalities such as the design and analysis of efficient computational learning methods are obviously central to the topic. [[@Angluin_1992]]

_Note: The topic of computational learning theory is somewhat hard to distinguish form the body of work surrounding modern [[Overview of machine learning]] methods, and appears to be relatively obscure._ 

Computational learning theory can be thought of as a sibling to [[Overview of statistical learning | Statistical learning]], which uses formal methods to analyse learning algorithms rather than the complexity of tasks. However, there is apparently a lot of overlap between the two in modern texts.

# PAC learning
The goal of the [[PAC-learning]] framework is to understand how large a data set needs to be in order to give good generalization. It also gives bounds for the computational cost of learning the task. 

# VC dimension 
Vapnik–Chervonenkis theory (VC) refers to a theoretical machine learning framework developed by Vladimir Vapnik and Alexey Chervonenkis, and seeks to quantify the capability of a learning algorithm.
