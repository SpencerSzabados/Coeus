A residual network is a type [[Artificial neural networks|artificial neural network]] with _skip connections_, links between non-adjacent layers in the network, used to carry unmodified values from a previous layer to another deeper layer while skipping over intermediate layers. The use of skip connections is made in the attempt to avoid quickly vanishing gradients that occur in training; thus, leading to a more easily optimized network. [Wiki](https://en.wikipedia.org/wiki/Residual_neural_network).
