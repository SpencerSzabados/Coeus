For task that involve sequential input (e.g., speech and language) it is often better to use RNNs. As these process input sequentially while maintaining a hidden "state vector" that implicitly contains information about the history of all the past elements of the sequence. The application of backpropagation in training RNNs is structured by inspecting the hidden state vectors at different discrete time steps and treating these as if they were the outputs of different neurones in a deep multilayer network. As such, training RNNs has shown to the problematic since the backpropagated gradients can grow or shrink dramatically when taken over multiple time steps, see [[@Bengio_1994]].
