

**Definition: (Cone)** A set $C$ is called a _cone_ (or nonnegative homogeneous) if for every $x\in C$ and $\theta\geq 0$, $\theta x\in C$. A cone is convex if for any $x_1,x_2\in C$ and $\theta_1,\theta_2\geq 0$ we have $\theta_1x_1+\theta_2x_2\in C$.

The conic hull of a set of points can be defined in terms of conic combinations; specifically, given a set of points $\{x_1,x_2,\dots,x_k\}$ the associated conic hull is $$\{\theta_1x_1+\cdots+\theta_kx_k\mid \theta_i\geq 0 \text{ for all }i=1,\dots,k\}$$which coincides with the smallest convex cone that contains $\{x_1,x_2,\dots,x_k\}$.


The set of all [[Semidefinite matrix|positive semidefinite matrices]] is a convex cone.
