A vector field is a class of functions distinguished by their topological properties; being a set of functions that assign a vector valued quantity to each point in the range space. 

The following is the common definition of a vector field for Euclidean space:

**Definition: (Vector field)** Given a subset $\Omega\subseteq \mathbb{R}^d$, a _vector field_ is a vector-valued function with codomain of the form $f:\Omega\to\mathbb{R}^D$. 

In the most stringent setting, typically $d=D$, however, this is not always assumed. See [Quora](https://www.quora.com/Does-a-vector-field-must-have-to-be-a-function-which-takes-same-number-of-input-and-same-number-of-output).
