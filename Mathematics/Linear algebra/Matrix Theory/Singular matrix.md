
**Equivalences: (Invertible matrices)** If $A$ is a invertible matrix (singular) then the following are equivalent: ^afc451
 1) $det(A)\neq 0$; 
 2) $A$ can be written as a product of elementary matrices;
 3) The RREF of $A$ is $I$;
 4) $A$ does not have $0$ as an eigenvalue;
 5) $Ax=0$ has only the trivial solution;
 6) $Ax=b$ has a unique solution for all values of $b$, and is consistent for all $b$.

**Theorem: (Diagonal matrix inverse)** If $D=diag(d_1,d_2,\dots,d_n)$ is a $n\times n$ diagonal matrix, then it posses an inverse if and only if all its entries along the main diagonal are nonzero, whereby its inverse is given as $$D^{-1} = diag(1/d_1,1/d_2,\dots,1/d_n).$$
