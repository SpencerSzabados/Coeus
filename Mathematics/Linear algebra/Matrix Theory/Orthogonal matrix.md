A matrix is said to be orthogonal is its rows and columns are mutually orthogonal vectors.

**Definition: (Orthogonal matrix)** A matrix $A$ is orthogonal if $AA^\intercal = A^\intercal A = I$; that is, $A$ is orthogonal if $A^\intercal = A^{-1}$.

Consequently orthogonal matrices are necessarily [[Symmetric matrix#^00e6e9|normal]].

**Theorem: (Equivalences)** If $A$ is an orthogonal matrix the following are equivalent:
  1) $\|Ax\|=\|x\|$ for all $x$;
  2) $Ax\cdot Ay = x\cdot y$ for all $x$ and $y$; (this comes from the above)
  3) $det(A)=\pm 1$
