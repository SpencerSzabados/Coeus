**Definition: (Locally constant function)** Let $f:X\to S$ be a function from a topological space $X$ to a set $S$. The function $f$ is called _locally constant_ at $x\in X$ if there exists a neighbourhood $U\subseteq X$ containing $x$ such that $f(x)=f(t)$ for all $t\in U$.

If $X$ is a connected topological space then $f$ is a constant function (across $X$) if it is locally constant.
