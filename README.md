# Obsidian Vault

## Description
This repository contains a backup of my primary [Obsidean](https://obsidian.md/) Vault that was developed during my Graduate Degree (2023-01 to 2025-01) in Machine Learning at the University of Waterloo and tail end of my Undergraduate Degree. In addition to the central notes on Statistics and Machine Learning, there are various notes about miscellaneous papers I've read, etc.

I am not distributing the content of `/references/figures/` due to licensing of some source materials. Figures and images will need to be sourced on your own from the references.

## Installation
Simply git-clone the repository into your Obsidian folder and import it through the application.

### Dependencies
A number of Obsidian community extensions are required to properly render and use all this vaults features; namely,
 + [obsidian-citations](https://github.com/hans/obsidian-citation-plugin) which is used for managing citations within MD files, and
 + [obsidian-git](https://github.com/denolehov/obsidian-git) for supporting automatic version control.
 + [obsidian-pseudocode](https://github.com/ytliu74/obsidian-pseudocode) for providing a pseudocode block.
 + [obsidian-keyword-flashcards](https://github.com/SpencerSzabados/obsidian-keyword-flashcards) for generating flashcards from notes.
