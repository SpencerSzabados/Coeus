# Overview
This paper deals with what the authors call class-selective rejection, a form of [[Classification and clustering#Set-valued (multi-set) classification|set-valued classification]], which is phrased as an alternative method to classifying inputs that cannot be reliably assigned to any one particular class and might otherwise be rejected (say due to no meeting some minimum threshold for prediction). 

The optimality studied is defined with respect to a tradeoff between output error rate and the average size of a assigned subset (prediction), where minimizing the number of classes is desirable whenever "confidence" in prediction is high. A Bayesian optimal solution (with respect to [[Maximum posterior|MAP]]) is given in the form (specification) of a class separator/boundary decision rule based on the proposed precision prediction size trad off objective. 


# Primary results
It is show that minimizing the average expected loss over the error rate and average number of classes predicted is optimal.

Suppose we are given data of the form $D=\{(X_i,Y_i)\}_{i=1}^N$ where $X\in\mathcal{X}$ and $Y_i\in\mathcal{Y}=\{C_1,\dots,C_K\}$. The predictions considered are of the form $\hat{Y}\in\mathcal{P}(\mathcal{Y})\backslash \{\emptyset\}$. To simplify notation, we assign indices $I$ to all possible subsets in $\mathcal{P}(\mathcal{Y})\backslash \{\emptyset\}$ such that the singleton set labels align with those of the associated class. Hereon in we only deal with subset and class labels. 

A matrix $L$ holds loss values $L_{ij}$ which are incurred for classifying an input $x$ which belong to the true class $i$ into subset $j\in I$ from $\mathcal{P}(\mathcal{Y})\backslash \{\emptyset\}$; note, the matrix $L$ is exponential in one of its dimensions. The learned decision rule $f:\mathcal{X}\to I$ assigns inputs to indices in the enumerated set of all possible subsets. The expected loss can then be stated is then $$E_D[L] = \int_X\left[\sum_{i=1}^K L_{i,f(x)}P(i|x)\right]\, p(x)dx.$$This quantity can be minimized by minimizing the integrand over all decision rules; in particular we are searching for $$f^*(x) = \arg\min_{j\in I}\left\{\sum_{i=1}^K L_{i,j}P(i|x)\right\}.$$

## Simple losses
In this initial decomposition the authors are using a single (common) cost value for every bad prediction and scalar for the size of the prediction. That is, the loss of rejecting the true class is equality series among all classes.

The problem of $L$ being exponential in one dimension can be aided by the introduction of a hierarchal loss structure based on the form of the individual subsets. In particular, the authors decompose $L$ into two smaller matrices, whose "combinatorial product" reflects the original matrix,  $M_{ij}$ measure the loss of missing the true class $c_i$ by choosing action $a_j$ and the matrix  $S_{j}$ stores penalty values for predictions of size $j$. Thus, $$L_{ij} = M_{ij}+S_j$$where $$M_{ij} = \begin{cases}0 & \text{ if } c_i\in s_j\\ l_m & \text{ otherwise,} \end{cases}$$and $$S_j = l_s|s_j|.$$
The above minimization argument for $f$ can then be reduced as $$\sum_{i=1}^K L_{i,j}P(i|x) = l_m\sum_{\substack{i=1\\ i\not\in s_j}}^K P(c_i|x)+l_s|S_j| = l_mR[x]+l_s n_j$$where $R$ is [[Empirical risk|risk]] and $n_j$ is the cardinality of subset $S_j$. This can be written as $$\sum_{i=1}^K L_{i,j}P(i|x) = l_mE[R[x]]+\bar{n}$$with $E[R[x]] = \int_X R[x]p(x)\, dx$ and $\bar{n}=\int_{X}n_jp(x)\, dx$ is the average prediction cardinality for input $x$. The optimal solution is then $$E[L]^* = l_mE[R[x]]^* + l_n\bar{n}^*,$$which is linear in terms of the error rate $E[R[x]]$ and average number of classes predicted.


### Optimization procedure
We are now in a position to optimize for $f$ via the above linear decomposition. In particular the authors decompose the problem thusly $$\min_{j\in I}\left\{\sum_{i=1}^K L_{i,j}P(i|x)\right\} = \min_{n\in \{1,2,\dots,K\}}\left\{\min_{|S_j|=n}\left\{l_m\sum_{\substack{i=1\\ i\not\in s_j}}^K P(c_i|x)+l_sn\right\}\right\}$$taken over all $x$ in $D$. Just as noted in [[@Mortier_2021]] the authors observe that for any specific cardinality only the subset $S_j$ that corresponds to the $n$ classes with highest posterior probabilities need to be considered, as this selection provides the minimizer in $O(K\log K)$ time. Thus, the posterior probabilities are sorted into descending order and labeled such that $\{P(i|x)\}_{i=1}^K\to \{Q(i,x)\}_{i=1}^K$ with $Q(i,x)\geq q(i+1,x)$ for all $i=1,\dots,K-1$. The inner minimization quantity in the above expression can then be reduced to $$\begin{align}\min_{|S_j|=n}\left\{l_m\sum_{\substack{i=1\\ i\not\in s_j}}^K P(c_i|x)+l_s|S_j|\right\} &= l_m\left(1-\sum_{i=1}^n Q(i,x)\right)+l_nn\\ &= l_m(1-F(n|x)) + l_nn.\end{align}$$The entire express then becomes $$\min_{j\in I}\left\{\sum_{i=1}^K L_{i,j}P(i|x)\right\} = \min_{n\in \{1,2,\dots,K\}}\{l_m(1-F(n,x))+l_nn\}.$$
Again as was similarly mentioned in [[@Mortier_2021]], if this minimized quantity admits a unique solution, it can be found once the sequence of values for any particular prediction size decreases the previously calculated values are all that are required to compute the optimal rule. This being due to the fact that the minimizing quantity is a convex function. 

The final decision rule can then be stated as follows. Select the $n^*$ best classes in terms of posterior probability $$n^* = \min_{i\in\{1,\dots,K\}}\{i\mid Q(i+1,x)\leq t\}$$where $t=l_n/l_m\leq 1/2$ is a loss threshold that balances the classification tradeoff of prediction size and $Q(K+1,x)=0$ by convention. These classes are then assembled into the final prediction. The final selection procedure can be selected in $O(K)$ time.

This optimization decision rule leads to $$E[R[x]]\leq t(K-\bar{n}_t)\leq t(K-1)$$where $\bar{n}_t$ is the average number of classes predicted for any value of $t=l_n/l_m$.


## More general losses
The loss structure is further generalized by allowing for different loss values to be incurred by the rejection of true classes over another class; that is, consider $$M_{ij} = \begin{cases}0 & \text{ if } c_i\in s_j\\ l_{m,i} & \text{ otherwise.} \end{cases}$$

### Optimization procedure
The optimal decision rule in this case becomes: If $\max_{i\in\{1,\dots,K\}}\{l_{m,j}P(i|x)\}\leq l_n$ then select $$\arg\max_{i\in\{1,\dots,K\}}\{l_{m,j}P(i|x)\}.$$Otherwise, select all classes such that $l_{m,j}P(i|x)>l_n$.
