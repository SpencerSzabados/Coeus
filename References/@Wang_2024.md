This paper presents a one-step "diffusion" model trained for generating robot actions, one action per sample, via a method of model distillation similar to the score matching used in [[@Song_2023]]. The [[@lu_2025]], which I believe is newer, also attempts to train a model to generate actions using one-step (or multi-sample) using consistency distillation.

The authors method experimentally achieves on the order of 42x speedup compared to multi-step (single) action sampling for partially observed robotics with video observations of the environment. The method rolls out single actions sequentially rather than entire trajectories, unlike [[@Janner_2022]] and [[@Carvalho_2024]], at least from what I can tell from the paper description; targeting robotics applications that need to adapt to changing environment or human interactions in real time, hence, the need for the method to perform in near real time.

The paper was reject due to the authors failing to provide sufficient empirical comparisons to existing methods and justifying the requirements for real time sampling speeds -- as I clarified above. The presentation of model parameterization in this paper is rather cumbersome and unclear.


# Primary results
The authors build on an existing framework, itself build on the forgoing works, using the discrete time diffusion formulation of [[@Ho_2020]] for robotics with partially observed environments via past image captures; namely, consider an environment $\Omega_t$ and a time indexed set of observation images (e.g., video sequence) $O=(O^{(i)})_{i=1}^H$, we seek to model an action policy using a DDPM model $p_\theta$ on $0\leq t\leq T$ s.t. $$\pi_\theta(A|O)=\int\frac{1}{Z}\exp\{-\frac{1}{2}A_T^\intercal A_T\}\prod_{t=1}^Tp_\theta(A_{t-1}|A_t,O)dA_T\dots dA_1$$where $A=(A^{(0)},\dots,A^{(K)})$ is a sequence of actions; and forward diffusion process $$A_t = \alpha_tA_0+\sigma_tz, \quad z\sim\mathcal{N}(0,\mathbb{I})$$using the VP-SDE drift and diffusion coefficients.

This formulation is intractable due to the state integration, so the authors parameterise the model in two different ways; however, frankly their proposed model that uses a separate score prediction network seems to lack novelty and can likely be implemented in a more elegant fashion, so I am only noting one combined version herein. 

Particularly, let $f_\phi$be a pre-trained DDPM diffusion model for generating actions parameterized in a form equivalent to $$f_\phi(A_t,t,O)=\frac{1}{\alpha_t}(A_t+\sigma_tD_\phi(A_t,t,O))$$and let $g_\theta$ be a generator network, the student network, parameterized such that the distribution is taken to be the single sample greedy sampling $$q_0(A|O)=\delta\{A-g_\theta(O)\};$$this is done to enable computation of the below gradient using a single network and remove instability from the score estimate that would result from using the one network for both score and action output values (hence why the authors use two networks for their stochastic method). Denote the induced transition probabilities of the matching diffusion processes of these models respectively by $p_t$ and $q_t$.

To train the student the authors propose using reverse [[Information theory#^272741|Kullback-Leibler divergence]] $$L_\theta = \mathbb{KL}(q_0|p_0)$$; however as these probabilities are intractable to evaluate, the loss is not explicitly computed, rather, the authors focus on estimating the losses gradient, resulting in the gradient weighted score matching $$\nabla_\theta \mathbb{KL}(q_0|p_0)=\mathbb{E}_{A=g_\theta(O),O\sim \mathcal{D}}[(\nabla_A\log q_0(A|O)-\nabla_A\log p_0(A|O))\nabla_\theta A];$$to improve stability in training the authors estimate this (loss) gradient by evaluating the following estimate over the diffusion trajectory $$\nabla_\theta\mathbb{E}_{t\sim\mathcal{U}\{1,\dots T\}}[\mathbb{KL}(q_t|p_t)]=\mathbb{E}_{\substack{t\sim\mathcal{U}\{1,\dots T\}\\z\sim\mathcal{N}(0,\mathbb{I})\\ A=g_\theta(z,O)\\ A_t\sim p_t(A)}}\bigg[\frac{\lambda(t)}{\sigma_t}(D_\phi(A_t,t,O)-z)\nabla_\theta A_t\bigg]$$
  in the following algorithm 
  ```pseudo
\begin{algorithm}
\caption{Action Distillation}
\begin{algorithmic}
\Input Let $D$ be the dataset of observations, $\{t_i\}_{i=1}^N$ be a discretization of the time horizon, $\eta$ the learning rate, $\delta$ the loss tolerance, $f_\phi$ a pre-trained diffusion model (with denoiser $D_\phi$) and $g_\theta$ be the initialised student model.
\Output Trained action model $g_\theta$.

    \While{$L > \delta$}
        \State Sample $O\sim D$
        \State Sample $z\sim \mathcal{N}(0,\mathbb{I})$
        \State Sample $i\sim \mathcal{U}\{2,\dots,N\}$
        \State Predict action $A\gets g_\theta(z,O)$
        \State Sample $A_{t_i}\sim \alpha_{t_i}A+\sigma_{t_i}z$\Comment{Forward SDE.}
        \State $\theta \gets \theta + \eta \frac{\lambda(t)}{\sigma_t}(D_\phi(A_t,t,O)-z)\nabla_\theta A_t$
    \EndWhile
\end{algorithmic}
\end{algorithm}
```


# Implementation 
For the implementation, environment observation images (e.g., video frames) are first processed using a ResNet18 encoder. This encoder is trained jointly with a 1D temporal convolutional network (CNN), which acts as the diffusion model's backbone; based on that from [[@Janner_2022]].
