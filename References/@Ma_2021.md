# Overview
The authors propose a method of performing [[Classification and clustering#Set-valued (multi-set) classification|set-valued prediction]] using [[Belief functions]] and utility maximization over a weighted average of values (similar to the particular form of loss function studied in [[@Mortier_2021]]?). The authors explore the theory of constructing good decision rules for forming predictions under the proposed framework. 


# Primary results
The authors being by define a _Ordered Weighted Average operator_, as given by another source, of dimension $d$ as a mapping $F_w:\mathbb{R}^d\to \mathbb{R}$ of the form $$F_w(a_1,\dots,a_d) = \sum_{i=1}^d w_ib_i$$where $b_i$ is the $i$-th largest element in the vector $(a_1,\dots,a_d)$ and $\sum_{i=1}^d w_i=1$. Clearly, the chosen values of the weights, $w$, dictates how the operator behaves. This behaviour can be summarised by the, so called, _orness_ measure $$orness(w) = \frac{1}{d-1}\sum_{i=1}^d (d-i)w_i,$$where the arithmetic average corresponds to $orness(w)=0.5$ etc. For a desired orness a set of optimal weights, those that maximize entropy, can be derived which satisfy a set of known properties based on the results of [Yager]; in particular, the values either form an increasing or decreasing geometric sequence. (Does the class of functions studied in [[@Mortier_2021]] for the construction of a loss function include geometrically increasing and decreasing functions; i.e., exponentials?)

Now, consider a training data set $X=\{(x_1,y_1),(x_2,y_2),\dots,(x_N,y_N)\}$ of vector label pairs with $y_i\in\{C_1,\dots,C_K\}$ from a the set of potential classes which make up the frame of discernment $\Omega$, with basic belief assignments of the form $m:\mathcal{P}(\Omega)\to [0,1]$. 

Rather than considering loss the authors use utility values, same form as the cost values considered in [[@Denoeux_2000]], which consist of individual costs, $0\leq l_{ij}$, that are earned as a result of assigning an input $x$ to a class $C_i$ when it has true class $C_j$. These values are arranged into a matrix $U$ of size $k\times k$, called the utility matrix. (In precise zero-one loss classification this reduces to $U$ being  diagonal.) It is assumed, without loss of generality, that $0\leq l_{ij}\leq 1$ for all $i\neq j$ and $l_{ij}=1$ when $i=j$.  

It is not mentioned until later in the text but these utility values are derived using belief functions, with masses learned from training data.

To deal with partial assignments, that is to say set-valued classifications, $U$ is extended to size $(2^k-1)\times k$ to include all possible predictive set formed from elements of $\mathcal{Y}$ excluding the empty set. Denote this extended matrix by $\tilde{U}$. The construction of the extended utility values within $\tilde{U}$ is key to the functioning of this predictive method since it directly effects how decision policies used; e.g., a decision making policy that does not account for anything other than utility values, meaning it is indifferent to imprecision, would simply return the largest set possible to maximize the utility score. 

The extended values $\tilde{l}_{Aj}$ within $\tilde{U}$, with index $A\subseteq \mathcal{Y}$, are constrained into the range $\bar{l}_{ij}\leq \tilde{l}_{Aj}\leq \max_{C_i}l_{ij}$, where the lower bound $\bar{l}_{ij}=\frac{1}{K}\sum_{C_i}l_{ij}$  corresponds to the expected utility gained by picking a class at random. Beyond this the extended values are assumed to result from a ordered weighted average of the original utility values found in $U$; that is, $$\tilde{l}_{Aj} = F_w(\{l_{ij}\mid C_i\in A\}) = \sum_{n=1}^{|A|} w_nl^{A}_{nj},$$where $l^{A}_{nj}$ denotes the $n$-th largest element in the set of utility values associated with $A$. 

Now given a user specified tolerance to imprecision, say $\gamma$, as specified by orness, a set of weights is found using maximum entropy that satisfy $$\sum_{n=1}^{|A|}\frac{|A|-n}{|A|-1}w_n=\gamma.$$
Predictions can then be made using one of several possible criteria. The authors give several possible criteria (any criterion that forms a complete preorder over $\mathcal{P}(\mathcal{Y})$ can be used but it is not guaranteed to be effective), I will only write about the Pignistic criterion which averages the utilities within each focal set (predicted set); that is we are selecting sets that yield the highest average utility, which is equal to $$\sum_{A\subseteq \mathcal{Y}}m(A)\left(\frac{1}{|A|}\sum_{C_i\in A} l_{ij}\right),$$ subject to the constraint of $\gamma$.
