This paper presents a offline goal-conditioned reinforcement learning (GCRL) method that takes inspiration from diffusion (generative models) for training a generative model using behaviour cloning. The method targets the same set of applications as [[@Wang_2024]], [[@Janner_2022]], [[@lu_2025]], but generates the trajectory sequentially using a single inference step per trajectory waypoint. 

Unlike other GCRL focused methods this model does not directly learn a value function, in order to determine the policy, rather it directly models the policy using a parameterised Gaussian in a similar fashion to [[@Ho_2020]].

The method experimentally out-performs [[@Janner_2022]] both in terms of rewards and inference time; with a ~10x speed up across various tasks.

Note, the authors reverse the conventional diffusion time indexing notation to align with with RL notation for time horizons. I swap the notion to align with the diffusion convention when possible.


# Primary results 
The problem considered can be formalised using RL nomenclature as follows. Consider a [[Markov decision process]] $(\mathcal{S},\mathcal{A},P,r,\mu,\gamma)$ augmented with a goal space $\mathcal{G}=\{\phi(s)|s\in\mathcal{S}\}$, where $\mathcal{S}$ and $\mathcal{A}$ are state and action spaces; $\phi$ is a known state-to-goal mapping (e.g., robot joint space to absolute position); $P$ is the transition probability, $P:\mathcal{S}\times\mathcal{A}\times\mathcal{S}\to [0,1]$; and $r:\mathcal{S}\times\mathcal{A}\times\mathcal{G}\to \mathbb{R}$ is the reward function; $p_T$ is the initial state distribution; and $\gamma\in (0,1]$ is the discounting factor for the future rewards. 

Then, the general task (in the online setting) is to optimise a policy $\pi:\mathcal{S}\times\mathcal{G}\to\mathcal{A}$ with respect to a given target distribution of desired (terminal) goals $p_0$ $$\mathbb{E}_{g\sim p_0,s_H\sim \mu,a_t\sim\pi(a|s_t,g),s_{t-1}\sim P(s|s_t,a_t)}\bigg[\sum_{t=0}^H \gamma^tr(s_t,a_t,g)\bigg];$$however, in GCRL the agent can't interact with the environment but rather only has access to a static dataset $D=\{(\tau^{(i)}, g^{(i)})\}_{i=1}^N$ of (time reversed) trajectories (rollouts), where $\tau=(s_H,a_{H-1}, \dots,a_0,s_0)$, generated from some policy $\pi_\beta$ that we attempt to clone (or improve). 

Given this setup, the authors propose treating $\pi_\beta$ as a diffusion process with a stationary forward transition kernel $q(s_t|s_{t-1})$, which is analytically unknown, and learning the time reversed process $P(s_{t-1}|s_t, \pi_\theta(a_t|s_t,g))$ parameterised in terms of the policy network $$\pi_\theta(a_t|s_t,g)=\mathcal{N}(a_t;\mu_\theta(s_t,g,u),\sigma^2_\theta(s_t,g,u)\mathbb{I})$$where $u\in\{1,\dots,T\}$ is a diffusion index and $T$ controls the number of diffusion steps that occur over the trajectory time horizon $H$ with mapping $t=\kappa(u)=\lfloor \frac{u}{T}H \rfloor$; this model is trained to optimise the NLL $$\theta = \arg\max \mathbb{E}_{(s_t,a_t,g,u)\sim \mathcal{D}}[\log \pi_\theta(a_t|s_t,g,u)].$$
That is, for some diffusion time index $u$ the reverse state transition induced by the learned policy is $$P_\theta(s_{t-1}|s_t,g,u)=\int_\mathcal{A}P(s_{t-1}|s_t,a)\pi_\theta(a|s_t,g,u)da;$$which acts as the "denoising" kernel in the diffusion process.

In order to augment the dataset $\mathcal{D}$, simulating the environment dynamics, the authors propose a parametric machine learning approach and a "non-parametric" trajectory stitching approach; I use quotes since the method relies on learning a latent space embedding function so I hesitate to call it non-parametric. I will only discuss the parametric approach, which bares resemblance to a model distillation method.

To approximate the kernel $q$, the authors use a conditional VAE parameterised in terms of the state conditional encoder  $f_\phi:(s,a)\mapsto z\sim \mathcal{N}(\mu_z,\sigma^2_z\mathbb{I})$ and decoder $g_\psi:(s,z)\mapsto a\in \mathcal{A}$ to generate potential actions (not goal conditioned) and a learned dynamics model $d_\omega: (s_0,a_0,\dots,s_t,g_\psi(s_t,z))\mapsto s \in \mathcal{S}$ which tries to predict what state will result from an action. The dataset can then be augmented by randomly sampling trajectories and resampling tail sections of them (keeping the goals intact)

The reverse dynamics model components are trained using 
  ```pseudo
\begin{algorithm}
\caption{Encoder-decoder training}
\begin{algorithmic}
\Input Let $\mathcal{D}$ be the dataset of reversed trajectories, $\eta$ the learning rate, $\delta$ the loss tolerance, and $\phi$ and $\psi$ initial model states.
\Output Trained action dynamics models $f_\phi$ and $g_\psi$.

    \While{$L > \delta$}
        \State Sample $\tau\sim \mathcal{D}$
        \State Sample $(s_t,a_t,s_{t-1})\sim\mathcal{U}(\tau)$\Comment{Take a slice.}
        \State Sample $z\gets f_\phi(s_t,a_t)$
        \State $L\gets (a_t-g_\psi(s_t,z))^2 + \mathbb{KL}[f_\phi(s_t,a_t)|\mathcal{N}(0,\mathbb{I})]$
        \state $\phi\gets \phi + \eta\nabla_\phi L$
        \state $\psi\gets \psi + \eta\nabla_\psi L$
    \EndWhile
\end{algorithmic}
\end{algorithm}
```
  ```pseudo
\begin{algorithm}
\caption{Dynamics model}
\begin{algorithmic}
\Input Let $\mathcal{D}$ be the dataset of reversed trajectories, $\eta$ the learning rate, $\delta$ the loss tolerance, $g_\psi$ a trained action generator, $\omega$ initial model state.
\Output Trained dynamics model $d_\omega$.

    \While{$L > \delta$}
        \State Sample $\tau\sim \mathcal{D}$
        \State Sample $t\sim \mathcal{U}\{0,\dots, H\}$
        \State $L\gets (s_t - d_\omega(s_H,a_{H-1},\dots, s_{t+1},a_t))^2$
        \state $\omega\gets \omega + \eta\nabla_\omega L$
    \EndWhile
\end{algorithmic}
\end{algorithm}
```

The data set is then augmented using the trained model components following the procedure 
  ```pseudo
\begin{algorithm}
\caption{Encoder-decoder training}
\begin{algorithmic}
\Input Let $\mathcal{D}$ be the dataset of reversed trajectories, $N$ number of new trajectories to generate, and $f_\phi$, $g_\psi$, and $d_\omega$ be the trained dynamics model components.
\Output Augmented dataset $\mathcal{D}$

    \For{$i=1,\dots,N$}
        \State Sample $\tau\sim \mathcal{D}$
        \State Sample $t\sim \mathcal{N}\{0,\dots,H\}$
        \State $\tau' \gets \tau[H:t]$
        \For{$k=t,\dots,1$}
            \State Sample $z\sim \mathcal{N}(0,\mathbb{I})$
            \State Sample $a_{k-1}\sim g_\psi(s_H,a_{H-1},\dots,s_k)$
            \State $s_{k-1}\gets d_\omega(s_H,a_{H-1},\dots,s_k,a_{k-1})$
            \State $\tau'[k-1] \gets (a_{k-1},s_{k-1})$
        \EndFor
        \State $\mathcal{D}\gets \mathcal{D}\cup \tau'$
    \EndFor
\end{algorithmic}
\end{algorithm}
```

Given the augmented dataset, the authors train the policy model following the algorithm 
  ```pseudo
\begin{algorithm}
\caption{Policy model training with diffusion horizon $T$}
\begin{algorithmic}
\Input Dataset $\mathcal{D}$ of augmented trajectories with goals, 
number of diffusion timesteps $T$, learning rate $\eta$, loss tolerance $\delta$, initial policy $\pi_\theta$.
\Output Trained policy $\pi_\theta$.

    \While{$L > \delta$}
        \State Sample $\tau=(s_H,a_{H-1},...,s_0,g)\sim \mathcal{D}$
        \State Sample diffusion step $u \sim \mathcal{U}\{1,...,T\}$
        \State Map to trajectory index $t \gets \kappa(u)=\lfloor \tfrac{u}{T}H \rfloor$
        \State Extract $(s_t,a_{t-1},g)$ from $\tau$
        \State Compute Gaussian NLL:
              $L \gets \tfrac{1}{2}\big[
                \|a_{t-1}-\mu_\theta(s_t,g,u)\|^2 / \sigma^2_\theta(s_t,g,u)
                + \log \sigma^2_\theta(s_t,g,u)\big]$ 
        \State Update parameters: $\theta \gets \theta - \eta \nabla_\theta L$
    \EndWhile
\end{algorithmic}
\end{algorithm}

```
