# Overview
This paper puts forwards a method of forming set-valued predictions based on [[Belief functions]] using specific lattice (po-set) constructions to reduce the complexity of the search space from $2^{2^{|\Theta|}}$ to $2^{|\theta|}$ (this is the search space for optimizing the belief in a set based on combining evidence from all basic probability assignments).
