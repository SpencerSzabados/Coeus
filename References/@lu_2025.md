This paper proposes using consistency distillation, following the technique from [[@Song_2023]], for application in speeding up robotic action generation; the motivation is identical to [[@Wang_2024]], however, the the methods differ in training loss and that this paper focuses on point cloud data as input (produced from sparse sampling of a depth camera) whereas the latter uses input video frames.

The model developed by the authors manages to achieve a ~10x (~16ms per action) speedup over the selected DDPM [[@Ho_2020]] baseline  model. 

# Primary results 
The authors build on the framework of model distillation proposed in [[@Song_2023]] following a similar conditioning method as used in [[@Wang_2024]]; namely, the authors focus on imitation learning of a policy. Given an environment $\Omega_t$ and a time indexed set of observations (past frames from fixed RGB-D camera observing the robot end-effector, so called eye-to-hand, sub-sampled using farthest point sampling) $O=(O^{(i)})_{i=1}^H$, we seek to model an action policy using a DDPM model $p_\theta$ on $0\leq t\leq T$ s.t. $$\pi_\theta(A|O)=\int\frac{1}{Z}\exp\{-\frac{1}{2}A_T^\intercal A_T\}\prod_{t=1}^Tp_\theta(A_{t-1}|A_t,O)dA_T\dots dA_1$$where $A=(A^{(0)},\dots,A^{(K)})$ is a sequence of actions; and forward diffusion process $$A_t = \alpha_tA_0+\sigma_tz, \quad z\sim\mathcal{N}(0,\mathbb{I})$$using the VP-SDE drift and diffusion coefficients.

The authors proceed, directly, to model $\pi_\theta$ as a deterministic policy $\pi_\theta(A|O)=\delta\{A-f_\theta(O)\}$ using a consistency model $f_\theta$, which is parameterised in terms of $$f_\theta(A,t,O)=c_{skip}(t)A+c_{out}(t)F_\theta(A,t,O)$$where $F_\theta$ is a network trained to predict the action directly with the [[@KarrasAAL_2022]] coefficients $$c_{skip}(t)=\frac{s^2}{\beta^2t^2+s^2}\quad \text{and}\quad c_{out}(t)=\frac{\beta t}{\sqrt{\beta^2t^2+s^2}}$$where $s$ is selected to be the variance of the data distribution (tuned parameter) and $\beta$ is the timestep scaling parameter; note, these coefficients only satisfy the consistency boundary condition for exactly $t=0$ and do not include the modification made in [[@Song_2023]] for scaling these value in $t\leq \epsilon$. 

The model is trained following the algorithm in [[@Song_2023]] or [[@Zheng_2024]]


# Implementation 
The condition observation vector, $O$, is composed of the last two time steps which are sub-sampled using the farthest points sampling and then embedded into the model using an MLP encoder. The model is made to predict the next four actions while only two are executed per prediction. 


# Extraneous notes
The contributions in this paper are minimal, and the paper lacks detail in terms of mathematical rigour and model formulation; nonetheless, the model performs well.
