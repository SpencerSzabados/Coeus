# Overview
The authors propose a method of incorporating a [[Belief functions|belief functions]] (see [[Evidence base classification]]) into a CNN based classifier which forms [[Classification and clustering#Set-valued (multi-set) classification|set-valued classifications]]. This approach was explored as the authors wanted an method that can perform consistently when dealing with outliers, i.e., they wanted a method capable of outputting predictions in all circumstances rather than opting to reject to perform predictions in the face of low model confidence. 

The method of performing set-valued classification considered is based on ([[Bayesian probability theory]]) utility functions, where any prediction is weighed on its inclusion of the true underlying class and the size of the prediction (detrimental to be large). This is a similar approach taken by [[@Mortier_2021]].


# Primary results
Suppose we are given training data of the from $\{(X_i,Y_i)\}_{i=1}^N$ from an underlying distribution $P(X,Y)$ defined on $\mathcal{X}\times \mathcal{Y}$ where $\mathcal{Y}=\{C_1,\dots,C_K\}$ is a set of classes. Then the set of possible outputs from the classifier is $\hat{Y}\in \mathcal{P}(\mathcal{Y})\backslash \{\emptyset\}$; the empty set is removed as outlier rejection is not considered.

The utility values for class assignment to a input $x$ are computed by weighting the evidence provided by similar training inputs, must like in [[@Denoeux_2000]], with the basic mass assignments $$\begin{align*}
    m_i(C_j) &= \alpha g_i(d(x,x^{(i)}))\\ 
    m_i(\mathcal{Y}) &= 1-\alpha g_i(d(x,x^{(i)}))
\end{align*}$$with it taken that $g_i(t) = \exp(-\eta_i t)$; note, this happens to be a function of the form studied in [[@Mortier_2021]]. The values of $\eta$ and $\alpha$ can be left as a learned parameters or if you want to make user of class prototypes can be taken as the degree of similarity between $x$ and the $i$-th class prototype. These mass are computed over the entire training set (or class prototype selection) and combined using Dempster's combination rule (or one of the plethora of other combination rules developed).

The resulting utilities are arranged into a matrix $U$ which is then extended to $\tilde{U}$ of size $2^K-1\times K$ to accommodate set-valued predictions in the same fashion as done in [[@Ma_2021]].

The decision criteria proposed by the authors is based around _lower_ and _upper expected utilities_ provided from the inclusion of class $C_i$ into the predictive set and are defined respectively as $$\begin{align*}\underline{E}[u(C_i,A)] &= \sum_{B\subseteq \mathcal{Y}}m(B)\min_{C_j\in B} \tilde{u}_{Aj}\\ \bar{E}[u(C_i,A)] &= \sum_{B\subseteq \mathcal{Y}}m(B)\max_{C_j\in B} \tilde{u}_{Aj}\end{align*}$$where $\tilde{u}_{Aj}$ is the extended utility value provided by including class $C_i$ within the prediction set $A$ when an input $x$ has true class $C_j$. It is assumed, as in [[@Ma_2021]], without the loss of generalization that $0\leq u_{ij}\leq 1$. 

From this the weighted expected utility value $$E[u(C_i,A)] = \gamma\underline{E}[u(C_i,A)]+(1-\gamma)\bar{E}[u(C_i,A)]$$is constructed, where $0\leq \gamma\leq 1$ is a user defined parameter that expresses the level of pessimism the predictor should operate under; that is, $\gamma$ encodes the level of acceptable risk the user is comfortable with in trade for more precise, but possibly incorrect, predictions.  

The final prediction $Y^*$ is then chosen to be $$Y^* = \arg\max_{A\subseteq\mathcal{Y}}\{\underline{E}[u(C_i,A)]+(1-\gamma)\bar{E}[u(C_i,A)\}.$$
