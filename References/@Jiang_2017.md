# Overview 
The paper proposes a kind of [[Variational autoencoder]], called a variational deep embedding model, with a [[Mixture model]] as the latent space for the embedding. This model, like with VAEs, uses sperate encoder and decoder networks. 

The main motivations for using a mixture model for the latent space embedding is in attempting to force the network to better [[Classification and clustering#Clustering|cluster]] observations through embeddings. It is thought such a model would more accurately generate samples belonging to specific subclasses within the distribution with these regions being better separated within the latent space.

Importantly, the proposed method does not need data labels during training, as the clusters are intended to emerge from the learned embeddings themselves in a [[Unsupervised learning|unsupervised]] fashion.


# Primary results 
The generation process being modeled assumes there are $K$ classes (clusters) $C_1,C_2,\dots,C_k$, each of which are fit as normal distributions. A sample $X\in\mathbb{R}^d$ is generated by first sampling a specific cluster's $C_i$ distribution $Z\sim N(\mu_i,\sigma^2_i\mathbb{I})$ and decoding, through the decoder network $d_\phi(z)$, the mean $\mu_x$ and variance $\sigma^2_x$ of $X$, $(\mu_x,\sigma^2_x) = g_\phi(z)$, and then drawing a sample $X\sim N(\mu_x,\sigma^2_x\mathbb{I})$.

Note, all the mixing between distributions takes place in the decoder network $d_\phi$ itself.

That is, the joint probability $P(x,z,c)$ is factored as $$P(x,z,c)=P(x|z)P(z|c)P(c)$$where $X$ and $C$ are independent when conditioned on $Z$ ([[Fundamentals of probability theory#^1bae84|conditional independence]]). 

Now, to see how training is carried out on this network, suppose we are given a set of observations $D=\{\vec{X_1},\dots,\vec{X_N}\}$, with $\vec{X_i}=(X_{i1},\dots,X_{id})$ which belong to a set of $k$ classes $\mathcal{C} = \{C_1,\dots,C_k\}$ each of which having an associated unknown mean value $\mu_1,\dots,\mu_k$ and variance $\sigma^2_1,\dots,\sigma^2_k$, as outlined above, or more generally we assume $X\sim p$ and we attempt to approximate $p$ using a mixture. 

This network is trained using [[Maximum likelihood]] on sample points, in particular, the [[Evidence lower bound]] is used fit the variational posterior $q(z,c|x)$, which assumed to be factorable as $q(z,c|x)=q(z|x)q(c|x)$, to the true posterior $p(z,c|x)$; that is, we are attempting to maximize  $$\log p(x) \geq E_{q(z,c|x)}\left[\log\left(\frac{p(x,z,c)}{q(z,c|x)}\right)\right]=EL(x)$$which by the above factorization conditions can be rewritten as $$EL(x)=E_{q(z.c|x)}[\log p(x|z)+\log p(z|c)+\log p(c) -\log q(z|x) -\log q(c|x)].$$
We cannot directly compute the evidence lower bound, at least not easily, as we cannot compute the expectation over the variational posterior, see [StackEchange-shimao](https://stats.stackexchange.com/a/408188), so instead the authors use stochastic gradient variational Bayes (SGVB) to estimate the evidence lower bound. In particular, the above expansion is approximated as: 

An encoder network $h_\theta(x)$ is responsible for modeling the factor $q(z|x)$ of the variationally posterior, with $(\hat{\mu},\log \hat{\sigma}^2) = h_\theta(x)$ and $q(z|x)=N(z|\hat{\mu},\hat{\sigma}^2\mathbb{I})$. Likewise, the value of $\mu_x$ is computed using a decoder network $g_\theta(z)$ where $z$ is a sample generated using the reparameterization trick of sampling $\epsilon \sim N(0,\mathbb{I})$ and setting $z=\hat{\mu}+\hat{\sigma}\odot \epsilon$. These terms plug directly into the above expansion, but we still need a method of approximating/modleing $q(c|x)$. The authors deal with this by writing the evidence lower bound in terms of the [[Information theory#Kullback-Leibler divergence|Kullback-Leibler divergence]], that is $$EL(x) = \int_z q(z|x)\log\left(\frac{p(x|z)p(z)}{q(z|x)}\right)\,dz-\int_z q(z|x)\mathbb{KL}(q(c|x)|p(c|z))\, dz$$, and noting any $q(c|x)$ that maximizes this quantity would satisfy $\mathbb{KL}(q(c|x)|p(c|x))=0$.
